# Interactive Music Analytics Dashboard

## Overview
This project is an interactive music analytics dashboard developed using Python, SQLite and ipywidgets. The application allows users to explore music trends, analyse artist popularity, and identify top artists across different time periods.

## Features
- Genre analysis by year
- Artist popularity exploration
- Top 5 artists across custom year ranges
- Interactive GUI using sliders, text inputs and buttons
- Real-time database querying using SQLite

## Technologies Used
- Python
- Pandas
- SQLite
- ipywidgets
- Matplotlib
- Jupyter Notebook

## Project Structure
- menu.ipynb: Main GUI interface
- Artist.py: Artist analysis functions
- Genre.py: Genre analysis functions
- Top5.py: Top artist analysis
- Preprocessing.py: Data preprocessing logic

## Key Skills Demonstrated
- Interactive dashboard development
- SQL database integration
- Event-driven programming
- Data visualisation
- User behaviour analysis
- Modular Python development

## How to Run
1. Install required libraries
2. Open Jupyter Notebook
3. Run menu.ipynb
4. Use sliders and text inputs to explore data
