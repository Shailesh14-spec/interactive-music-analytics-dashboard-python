Sakar, C. & Kastro, Y. (2018). Online Shoppers Purchasing Intention Dataset. UCI Machine Learning Repository. [https://doi.org/10.24432/C5F88Q](https://doi.org/10.24432/C5F88Q). Dataset licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as stated by UCI. Accessed 25 October 2026.

Source archive: https://archive.ics.uci.edu/static/public/468/online+shoppers+purchasing+intention+dataset.zip

The downloader extracts `online_shoppers_intention.csv` from the archive, verifies its SHA-256, and saves the original bytes without changes. Raw data is not committed. Analysis-derived aggregate tables and charts are adaptations of this dataset; feature engineering and exclusions are described in the README and code.
